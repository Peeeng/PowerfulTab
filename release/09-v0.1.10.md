# PowerfulTab 0.1.10

状态：发布材料已准备，尚未上传商店或提交审核。

更新内容：

- 新增域名白名单，仅在按域名模式显示；名单内域名按一级 Path 分组。
- Path白名单仅在按 Path 模式显示；名单内域名按域名分组。两份名单独立保存，切换模式不清空，界面与原生整理使用相同规则，不影响去重。
- 新增“搜索清空时间”，默认 60 秒，0 关闭；每次输入或选择历史记录重新计时，中文选字期间暂停，超时清空当前搜索但保留记录。普通标签列表刷新不会重置计时。
- 设置提示改为名称右上角的 12px 小问号，悬浮或点击查看；问号不再可聚焦，避免打开设置时自动聚焦提示。
- “搜索框保留数”更名为“搜索记录保留”；两种白名单输入框与名称同行，宽度 220px、默认两行，窄界面自适应。
- “Path白名单”名称去除中间空格。已有设置和搜索记录保留，本版不增加权限或远端服务。

上传包：`release/dist.zip`，manifest 版本为 `0.1.10`。

上传步骤：

1. 登录 https://chrome.google.com/webstore/devconsole ，打开已有的 PowerfulTab 商品。
2. 在软件包页面上传 `release/dist.zip`；如更新详细介绍，可使用 `release/02-store-listing.md`。
3. 保存草稿，核对隐私披露和权限说明，完成后台要求后提交审核。
