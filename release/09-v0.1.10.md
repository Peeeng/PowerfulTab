# PowerfulTab 0.1.10

Status: release materials prepared; no confirmed store upload or review submission.

## Changes

- Added Domain whitelist, shown in Domain mode; listed hostnames use first-level path grouping.
- Path whitelist is shown only in Path mode; listed hostnames use domain grouping. Lists are independent, survive mode switching, and use the same rules in the UI and native organizing without affecting deduplication.
- Added Search clear delay (the setting was labeled in Chinese in this build), default 60 seconds, 0 disables. Input / history selection restarts it; IME composition pauses it. Search history is preserved, and ordinary list refreshes do not reset the timer.
- Moved settings hints to 12px question marks at the labels' upper-right corners; they cannot take focus.
- Renamed the Chinese search-retention label. Whitelist inputs are inline, 220px wide, and show two lines by default.
- Removed the space from the Chinese Path-whitelist label.
- Existing preferences / history are preserved; no new permissions or remote services.

Package: `release/dist.zip`, prepared with manifest `0.1.10`. Normal development builds do not replace this ZIP. English-default language selection is subsequent Unreleased work, not a feature of this prepared package.

## Upload

1. Open the existing PowerfulTab item at https://chrome.google.com/webstore/devconsole.
2. Upload the intended package after verifying its manifest version.
3. Use listing text that matches the uploaded build. Updated Unreleased listing text must not be applied to the older package without corresponding code.
4. Save the draft, verify policy disclosures / permissions, then submit for review.

Existing screenshots do not automatically change. If replacing them, use current, real, privacy-safe captures.
