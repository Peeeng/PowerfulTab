# PowerfulTab 0.1.11

Status: release materials prepared; no confirmed store upload or review submission.

Package: `release/dist.zip`, manifest version `0.1.11`.

- Added Language in Settings, with English as the default and Simplified Chinese as an option. Missing or invalid saved language values fall back to English; other preferences remain intact.
- Localized toolbar, search, settings and hints, tab actions, window picker, empty states, status messages, Undo, relative-time labels, and the fallback popup.
- Switching languages preserves the current query, history, native / planned groups, collapse state, list-order timers, and auto-clear countdown. Tab titles, URLs, and group names are not translated.
- Settings labels preview the selected language; Save applies it across views, while Cancel / outside dismissal discards it.
- Switched manifest descriptions, page titles, README, release documentation, permissions, privacy policy, and generated branding captions to English.
- No new permissions, remote translation calls, or uploaded data. Both dictionaries are bundled.
- Deduplicate is icon-only in both languages, retaining localized hover hints and accessible labels in the toolbar and fallback popup.
- Replaced the toolbar cat with a cheerful floppy-eared puppy while retaining the compact footprint, theme colors, and hover behavior.

The package has been built and its version synchronized with package / manifest / CHANGELOG. No new permissions were added. Native title hover hints are retained; their timing is controlled by Chrome.

## Store upload

1. Open the existing PowerfulTab item at https://chrome.google.com/webstore/devconsole.
2. Upload `release/dist.zip` and confirm version `0.1.11`.
3. Set the primary listing language to English and use `02-store-listing.md` for the updated text. In-extension language selection does not change the store listing automatically.
4. Verify the public English privacy policy and data-use / permission disclosures. Save the draft before submitting for review.
5. If replacing screenshots, capture the current English UI with public sample pages; do not upload private/internal information from older screenshots. Existing screenshots are not regenerated by packaging.
