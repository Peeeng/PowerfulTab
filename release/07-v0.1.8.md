# PowerfulTab 0.1.8

Historical preparation notes; not proof of upload or review submission.

- Added Chinese-title pinyin-initial search, such as `bd` for Baidu and `wx` for WeChat.
- Added space-separated keywords; all must match, in any order.
- Each keyword can match the title, URL, or initials independently. Repeated and outer whitespace is ignored.
- Search stays local with a bundled dictionary; no new permissions.

The package prepared for this version used manifest `0.1.8`. `release/dist.zip` is regenerated for later releases and is not a permanent historical artifact.

Upload version-appropriate packages to the existing item at https://chrome.google.com/webstore/devconsole, save the draft, and complete the dashboard requirements before review submission.
