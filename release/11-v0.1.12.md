# PowerfulTab 0.1.12

Status: release materials prepared; no confirmed store upload or review submission.

Package: `release/dist.zip`, manifest version `0.1.12`.

## Extension changes

- Removed default-value wording from English and Chinese settings hints; users can read current values in the controls.
- Language and Theme no longer display descriptions or question-mark hints.
- Existing preferences, actual default values, and behavior are unchanged. No new permissions or remote services.

## Screenshot assets

- Replaced the previous two captures with four supplied English UI captures: tab list, move-window dialog, settings, and pinyin-initial search.
- Kept originals and generated 1280×800, 24-bit RGB PNG without alpha.
- Added rounded floating-card framing, stronger two-layer shadows, and a pale background without changing output dimensions or distorting screenshot content.
- Subsequent unversioned asset update: card framing and shadows were reverted; current screenshot files use plain proportional resizing with white padding if needed. The extension ZIP is unaffected.
- Removed old size-suffixed aliases and stopped regenerating them.

These image assets are separate from the extension ZIP. They still contain internal hostnames and account/message information and must not be uploaded publicly before privacy review and redaction. The settings screenshot predates the description simplification; recapture it if exact current UI is needed.

## Store upload

1. Open the existing PowerfulTab item at https://chrome.google.com/webstore/devconsole.
2. Upload `release/dist.zip` and verify version `0.1.12`.
3. Use the English listing in `02-store-listing.md`; verify the public privacy policy and required data-use / permission disclosures.
4. Keep existing approved screenshots unless replacing them with reviewed, privacy-safe captures.
5. Save the draft, then submit for review after all dashboard requirements are satisfied.
