# PowerfulTab 0.1.15

Status: release materials prepared; no confirmed store upload or review submission.

Package: `release/dist.zip`, manifest version `0.1.15`.

## Change

Removed the optional `homepage_url` from the extension manifest. Chrome no longer uses the GitHub repository as the extension website through this setting. Store-installed versions may use the Chrome Web Store listing as the default homepage.

Window filters, configurable Recent count, and visit-time cleanup from 0.1.14 remain available. No permissions or data-processing behavior changed.

## Validation

- Production build and the 17 existing regression checks passed.
- Verified ZIP integrity, version consistency, the absence of `homepage_url`, and the existing permission list in the packaged manifest.

## Store upload

Upload `release/dist.zip` to the existing PowerfulTab item at https://chrome.google.com/webstore/devconsole and verify version `0.1.15`. Use the current English listing and existing permission / privacy materials. Record actual submission or publication only after confirmation.
