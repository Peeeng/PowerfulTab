# PowerfulTab 0.1.9

Historical preparation notes; not proof of upload or review submission.

- Added moving tabs to another window, selected by window ID, tab count, and active title.
- Compacted move / duplicate / close actions to 58px.
- Recent visit changes use a 500ms debounce; search and active highlights remain immediate.
- Default minimum 3 tabs and maximum 15 groups (including other), preserving saved preferences.
- Cleaned older branding and migrated local settings / history.
- Removed extension shortcut functionality; opening the interface still attempts to focus search.
- Preserved pinyin-initial and all-keyword search.
- Processing stays local; no new permissions.

The package prepared for this version used manifest `0.1.9`. The current `release/dist.zip` may belong to a later version; verify its manifest before upload.

Open the existing item at https://chrome.google.com/webstore/devconsole, upload a version-appropriate package, save the draft, and submit after validation.
