# PowerfulTab 0.1.13

Status: release materials prepared; no confirmed store upload or review submission.

Package: `release/dist.zip`, manifest version `0.1.13`.

## Extension changes

- Debounced title, favicon, loading-status, and other presentation-driven tab refreshes by 500ms. URL, pinning, and native group changes still refresh immediately.
- After tab deletion, removed rows and counts update immediately while displayed group membership and group order wait until 3s after the last deletion. Structural additions, navigation, moves, grouping-rule changes, and explicit Organize still apply immediately.
- Move skips the window picker when only one eligible destination exists. Multiple destinations still show the picker, and destination mode is rechecked.
- After moving a tab to another window, the destination window activates and focuses the moved tab so it is shown immediately.
- Toolbar status text now uses a separate full-width row below the puppy and controls, so grouping results do not push action buttons down. Long messages wrap.
- The puppy decoration no longer has a downward offset in dashboard and sidebar toolbars, keeping it aligned with controls and status text.
- The Organize button label remains stable while busy in both languages; disabled state and separate status text still indicate progress.

## Screenshot assets

- The four screenshots have been restored to plain proportional conversions from originals.
- Card framing, shadows, rounded corners, and decorative background were removed.
- Output remains 1280x800, 24-bit RGB PNG without alpha.

These image assets are separate from the extension ZIP. They still require privacy review before public upload.

## Store upload

1. Open the existing PowerfulTab item at https://chrome.google.com/webstore/devconsole.
2. Upload `release/dist.zip` and verify version `0.1.13`.
3. Use the English listing in `02-store-listing.md`; verify the public privacy policy and required data-use / permission disclosures.
4. Keep existing approved screenshots unless replacing them with reviewed, privacy-safe captures.
5. Save the draft, then submit for review after all dashboard requirements are satisfied.
