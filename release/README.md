# PowerfulTab · Chrome Web Store release materials

English listing text, permission explanations, policy instructions, and build tools. Real product screenshots must reflect the current UI, and the policy must be publicly hosted.

| File | Purpose |
| --- | --- |

| `02-store-listing.md` | English name, descriptions, single purpose, and keywords |
| `03-permissions.md` | Permission and data-use explanations |
| `04-privacy-policy.md` | Canonical English policy link and hosting instructions |

| `screenshots/` | Branding artwork and existing screenshots |

Current language changes are Unreleased. `npm run build` updates `dist/`, not the previous release ZIP. Select a new version and synchronize package / manifest / changelog / notes before a store update.

Store listing language is configured in the developer dashboard; selecting a language inside the extension does not change the existing store listing.
