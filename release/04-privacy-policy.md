# 04 · Privacy policy and publishing

The canonical English policy is [docs/privacy.md](../docs/privacy.md). Publish that file, not this deployment guide, and enter the public URL in the store's Privacy policy field.

The policy covers local tab metadata, both grouping whitelists, language and theme, search retention and clear delay, timestamps, permissions, and the developer contact. Check it against the actual build before submission.

## GitHub Pages

1. Commit and push the updated `docs/` folder to the repository.
2. In GitHub **Settings → Pages**, choose **Deploy from a branch**.
3. Select **main** and **/docs**, save, and wait for deployment.
4. Verify the full policy loads without login at the intended address:

```text
https://peeeng.github.io/PowerfulTab/privacy
```

5. Add that verified URL to the Chrome Web Store dashboard.

The intended URL is not proof of deployment. Do not claim it is live until verified. Contact: `Peeeng520@gmail.com`.
