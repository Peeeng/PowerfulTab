# PowerfulTab 0.1.14

Status: release materials prepared; no confirmed store upload or review submission.

Package: `release/dist.zip`, manifest version `0.1.14`.

## Extension changes

- Added multi-select colored window icons to the left of the tab/group summary below search. All resets the selection; window IDs and tab counts appear on hover. Group lists, Recent, and counts follow both window selection and search, preserving existing group membership. Filters remain available for empty search results.
- Window colors now use unused entries from the ten-color palette before repeating. Existing live windows retain their colors during a view session; closed windows release their colors for reuse. Filters and active-tab highlights share the allocation.
- Added Recent tab count to Settings, defaulting to eight. Saved counts apply to dashboard and side-panel views without closing tabs.
- Added Close old tabs to the toolbar. Its retention slider offers 1h, 2h, 6h, 12h, 1d, 2d, 3d, 5d, 7d, and 15d, initially selecting 3d. The dialog previews the count before confirmation.
- Cleanup applies to the selected windows independently of search. Pinned tabs, protected URLs, extension pages, and unknown visit times are retained. Visits and protection are checked again before closing only previewed candidates.
- Existing Undo is available for cleanup when Chrome supplies restorable sessions. Session queries respect Chrome's supported maximum and include closed-window sessions. Large batches may be only partly recoverable, as indicated in the dialog.
- No additional permissions, remote code, or uploads.

## Validation

- TypeScript / production build and the 17 existing regression checks passed.
- Focused checks covered window selection and colors, settings defaults / persistence, Recent counts in both languages, all retention presets, the cutoff boundary, protected / unknown visits, confirmation guards, fresh visit revalidation, preview restrictions, and the bulk Undo query limit.
- Tab-closing checks used simulated browser APIs. This does not claim live Chrome or store-review validation.

## Store upload

1. Open the existing PowerfulTab item at https://chrome.google.com/webstore/devconsole.
2. Upload `release/dist.zip` and verify version `0.1.14`.
3. Use the updated English listing in `02-store-listing.md` and the existing permission / privacy materials.
4. Test the unpacked build in Chrome before submitting, including window filters, Recent count persistence, and cleanup / Undo.
5. Save the draft and submit after the developer dashboard's requirements are satisfied. Record actual submission or publication only after confirmation.
